How it is used

When AI is on, Plan a Trip sends your destination, dates, budget, pace and interests to this model and saves the itinerary it returns. If the model fails, the planner falls back to the built-in template and tells you why.

Tips
  • Use Test Connection before saving: it tries the values in the form.
  • Models with larger outputs need a higher Max tokens for long trips.
  • Changing the base URL to a different server removes the saved key, so your key is never sent to a server you didn't enter it for.
  • Defaults can also be set in src/main/resources/ai.properties or with TM_AI_BASE_URL / TM_AI_API_KEY / TM_AI_MODEL.
